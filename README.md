# Flashcard Quiz App

An Android Flashcard Quiz application built as a **CodeAlpha** internship task using **Java** and **XML** in **Android Studio**.

## Features
- **Question & Answer Toggle:** Flip or toggle between the flashcard question and answer during study sessions.
- **Card Navigation:** Move forward and backward through flashcards with wraparound logic at the ends of the deck.
- **Flashcard Management (CRUD):** Create, view, edit, and delete flashcards dynamically.

## Project Structure & Architecture
- **`Flashcard.java`**: Data model representing a flashcard, using encapsulation with private fields and public getters/setters.
- **`activity_main.xml`**: XML user interface layout defining the card display, navigation controls, and management actions.
- **`MainActivity.java`**: Handles UI event listeners, quiz state management, card navigation, and CRUD operations.

## Tech Stack
- **Language:** Java
- **UI Layout:** XML
- **IDE & Testing:** Android Studio (tested on the Medium Phone emulator)
